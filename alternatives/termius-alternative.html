How to Migrate from Termius to SSH Desktop

Migrate your server connections and SSH keys in under 60 seconds without retyping host credentials.

In Termius, navigate to Settings → Data → Export to OpenSSH Config (~/.ssh/config).

Step 2: Auto-Import into SSH Desktop

Launch SSH Desktop. The initial setup detects standard OpenSSH configs, JumpHosts, and identity files automatically, organizing your servers into folders and tags.

Cancel your Termius recurring subscription. Gain dual-pane SFTP, in-place Monaco code editing, visual tunnels, and macOS desktop shell features immediately.
