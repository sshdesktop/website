FAQ

Frequently Asked Questions

Can I take live backups of active MySQL or PostgreSQL databases?

Yes. The backup orchestrator supports pre-backup and post-backup hooks. It can run mysqldump or pg_dump directly into a temporary stream, guaranteeing transactionally consistent database snapshots without stopping database engines.

How are retention policies configured?

You can define retention rules such as "Keep last 7 daily snapshots, 4 weekly snapshots, and 12 monthly snapshots". SSH Desktop prunes expired snapshots automatically after each successful run.

Does backup execution cause CPU spikes on production?

No. Backup tasks are automatically executed with ionice -c 3 (idle I/O priority) and nice -n 19 (lowest CPU scheduling), ensuring your web and database traffic experiences zero latency degradation.
