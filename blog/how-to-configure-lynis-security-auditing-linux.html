How to Configure Lynis for Linux Security Auditing: 2026 Guide

Securing Linux servers requires more than just enabling a firewall and applying periodic package updates. Compliance standards (like SOC 2, ISO 27001, and HIPAA) demand verifiable auditing of kernel parameters, file permissions, daemon configurations, and user authentication policies. Lynis is an industry-standard open-source auditing tool that evaluates hundreds of system checkpoints and delivers an actionable Hardening Index. Learn how to configure Lynis in 2026.

What Lynis Audits Across Your Server

  • Kernel Hardening: Inspects sysctl parameters (SYN cookies, ASLR, ICMP redirects, core dumps).
  • SSH Daemon Hardening: Evaluates cryptographic ciphers, root login policies, and session timeouts.
  • User Accounts & PAM: Flags dormant accounts, weak password policies, and excessive sudo permissions.
  • Filesystem Permissions: Detects world-writable files, missing noexec flags on /tmp, and unencrypted partitions.
  • Firewall & Network Ports: Audits active listening ports, iptables/UFW rules, and open RPC services.

Step 1: Install Lynis from Official Repositories

Install Lynis on Ubuntu or Debian:

# Import Cisofy signing key and repo
sudo apt update
sudo apt install -y apt-transport-https ca-certificates gnupg
curl -fsSL https://packages.cisofy.com/keys/cisofy-software-public.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/cisofy.gpg
echo "deb https://packages.cisofy.com/community/lynis/deb/ stable main" | sudo tee /etc/apt/sources.list.d/cisofy-lynis.list

sudo apt update
sudo apt install -y lynis

On RHEL, AlmaLinux, or Fedora:

sudo dnf install -y epel-release
sudo dnf install -y lynis

Step 2: Run Your First Full System Security Audit

Execute a comprehensive non-destructive audit as root:

sudo lynis audit system

Lynis tests over 300 checkpoints, categorized from authentication to storage. At the conclusion of the scan, Lynis provides:

  • Hardening Index (e.g., 68/100): An overall security posture grade.
  • Warnings: Critical security risks that require immediate mitigation.
  • Suggestions: Actionable hardening recommendations with direct CIS benchmark references.

Step 3: Review Warnings and Actionable Suggestions

Filter the audit output to display only high-priority suggestions and warnings:

# View high-priority warnings
sudo grep -E "Warning:" /var/log/lynis.log

# View hardening recommendations
sudo grep -E "Suggestion:" /var/log/lynis.log

To examine specific details on any suggestion code (such as SSH-7408 for SSH protocol hardening): 

lynis show details SSH-7408

Step 4: Create a Custom Scan Profile

Avoid false positives on specialized server roles (e.g., Docker hosts or reverse proxies) by customizing /etc/lynis/custom.prf: 

sudo nano /etc/lynis/custom.prf

Add custom audit preferences and skip unnecessary tests:

# Skip tests not applicable to your cloud environment
skip-test=KRNL-5830
skip-test=USB-1000

# Set compliance profile target
profile-name=Production Web Gateway Hardening

Step 5: Automate Weekly Security Audits with Cron

Create /etc/cron.weekly/lynis-audit for unattended scans:

#!/usr/bin/env bash
set -euo pipefail

REPORT_DIR="/var/log/lynis"
mkdir -p "$REPORT_DIR"

# Run non-interactive cron scan
/usr/sbin/lynis audit system --cronjob --profile /etc/lynis/custom.prf     --report-file "$REPORT_DIR/report-$(date +%F).dat"     --log-file "$REPORT_DIR/lynis-$(date +%F).log"

# Keep last 8 weeks of reports
find "$REPORT_DIR" -type f -mtime +60 -delete
sudo chmod +x /etc/cron.weekly/lynis-audit

Frequently Asked Questions

What is Lynis and what standards does it test against?

Lynis is an open-source battle-tested security auditing engine for Linux, macOS, and BSD systems. It performs non-destructive security scans against CIS Benchmarks, NIST SP 800-53, HIPAA, and PCI-DSS standards, generating a comprehensive Hardening Index score.

Does running a Lynis audit risk breaking running production services?

No. Lynis is strictly passive and non-destructive. It inspects file permissions, kernel sysctl parameters, daemon configs, and installed packages without altering system state, stopping services, or rewriting configuration files.

How can I automate weekly Lynis security scans and email the results?

You can execute lynis audit system --cronjob in a weekly cron file or systemd timer. Lynis suppresses interactive prompts and writes structured results to /var/log/lynis-report.dat and /var/log/lynis.log for automated parsing.
