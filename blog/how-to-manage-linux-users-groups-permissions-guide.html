How to Manage Linux Users, Groups & Permissions: Complete 2026 Guide

Published: November 2026 • 10 min read • By SSH Desktop Engineering Team

Sharing root credentials or allowing developers to log into production Linux servers using a shared generic username is one of the quickest ways to cause an accidental outage or fail a security compliance audit.

Linux is a multi-user operating system with strict permission boundaries. By creating individual named user accounts, assigning users to specific groups, granting sudo privileges properly, and mastering octal permissions (chmod) and ownership (chown), you maintain accountability and system security.

In this tutorial, you will master the essential commands to create and modify users, configure passwordless sudo, calculate octal permissions, and manage server accounts visually.

1. Creating Users: useradd vs adduser

Feature useradd (Low-Level Binary) adduser (Interactive Wrapper)
Availability Universal across all Linux distros Debian / Ubuntu standard (Perl script)
Home Directory Not created unless -m is passed Created automatically (/home/user)
Password Prompt Account created locked without password Prompts interactively for password
Default Shell Defaults to /bin/sh Defaults to /bin/bash

Creating a User on Ubuntu/Debian:

sudo adduser deployer

Creating a User on CentOS/RHEL/AlmaLinux:

# -m creates home dir, -s sets bash shell:
sudo useradd -m -s /bin/bash deployer
sudo passwd deployer

2. Granting Sudo Privileges

To give a user administrative privileges without sharing the root password:

On Ubuntu & Debian:

sudo usermod -aG sudo deployer

On CentOS, RHEL, & AlmaLinux:

sudo usermod -aG wheel deployer
The Vital -a Flag: Always include the -a (append) flag with -G. Running usermod -G sudo user without -a will remove the user from all other supplementary groups (such as docker or www-data)!

3. Decoding Linux Permissions: chmod Octal Math

Every Linux file and directory has permissions split across three entities:

  • Owner (User): The user who owns the file.
  • Group: The members of the file's assigned group.
  • Others (World): Everyone else on the server.

The Numeric Values:

  • Read (r): 4
  • Write (w): 2
  • Execute (x): 1
Octal String Owner Group Others Typical Target
755 rwxr-xr-x Read, Write, Exec Read, Exec Read, Exec Web directories, scripts
644 rw-r--r-- Read, Write Read Read Standard web files, HTML
700 rwx------ Read, Write, Exec None None ~/.ssh directory
600 rw------- Read, Write None None SSH private keys, authorized_keys

4. Changing Ownership: chown & chgrp

# Change file owner to deployer:
sudo chown deployer /var/www/html/index.html

# Change both owner and group simultaneously:
sudo chown deployer:www-data /var/www/html/index.html

# Recursively apply across entire directory:
sudo chown -R deployer:www-data /var/www/html/

5. Deleting Users Safely

When offboarding a developer or retiring an automated service account:

# Delete user but keep their home directory:
sudo userdel deployer

# Delete user AND remove their /home/deployer folder and mail spool:
sudo userdel -r deployer
