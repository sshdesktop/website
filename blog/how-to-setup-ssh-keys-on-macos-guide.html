How to Set Up SSH Keys on macOS: Complete 2026 Guide (Ed25519 & Keychain)

Published: November 2026 • 9 min read • By SSH Desktop Engineering Team

Whether you are a developer pushing code to GitHub, a DevOps engineer deploying to AWS EC2, or managing a home Linux lab from your MacBook, using cryptographic SSH keys is dramatically faster and safer than typing passwords.

However, macOS has a few unique quirks: Apple's custom OpenSSH fork handles passphrases differently, and without the proper configuration, your Mac will constantly prompt you for passphrases every time you restart your machine.

In this complete step-by-step tutorial, you will generate an elliptic-curve Ed25519 key pair, configure seamless Apple Keychain integration, copy your public key to remote Linux servers, and manage keys visually.

Step 1: Check for Existing SSH Keys

Open Terminal (press Cmd+Space, type "Terminal", and press Enter) and list the contents of your hidden SSH directory:

ls -la ~/.ssh

Look for existing keys like id_ed25519 or id_rsa. If they already exist and you want to keep them, skip to Step 3. Otherwise, create a clean modern key.

Step 2: Generate a Modern Ed25519 Key Pair

Do not generate legacy RSA keys. Modern OpenSSH servers deprecate RSA with SHA-1 signatures. Instead, generate an Ed25519 key:

ssh-keygen -t ed25519 -C "your_email@example.com"

Interactive Prompts:

  1. Enter file in which to save the key (/Users/you/.ssh/id_ed25519): → Press Enter to accept default.
  2. Enter passphrase (empty for no passphrase): → Type a strong passphrase (recommended).
  3. Enter same passphrase again: → Re-type your passphrase and press Enter.

Two files are created in ~/.ssh/:

  • id_ed25519 (Private Key): Your secret cryptographic identity. Never share, copy, or upload this file.
  • id_ed25519.pub (Public Key): The public counterpart that you freely upload to servers, GitHub, GitLab, and cloud providers.

Step 3: Save Passphrase Permanently in Apple Keychain

By default, macOS wipes loaded keys from memory on every restart. To instruct macOS to store your passphrase securely in Apple Keychain (protected by your Mac login and Touch ID):

Edit (or create) your local ~/.ssh/config file:

nano ~/.ssh/config

Paste the following configuration:

Host *
AddKeysToAgent yes
UseKeychain yes
IdentityFile ~/.ssh/id_ed25519

Press Ctrl+O then Enter to save, and Ctrl+X to exit nano.

Now, load the key into the agent and save it to the Apple Keychain:

ssh-add --apple-use-keychain ~/.ssh/id_ed25519

Enter your passphrase once. You will never be prompted for it again, even across system restarts!

Step 4: Copy Your Public Key to a Remote Linux Server

To log into your remote Ubuntu, Debian, or CentOS server without a password:

ssh-copy-id -i ~/.ssh/id_ed25519.pub user@your-server-ip

Enter your remote Linux user password one last time. ssh-copy-id appends your public key to the remote server's ~/.ssh/authorized_keys with proper permissions.

Now test connecting:

ssh user@your-server-ip

You are instantly logged into your server prompt with zero password prompts!

Step 5: Add Your SSH Key to GitHub / GitLab

Copy your public key directly to your macOS clipboard with pbcopy:

pbcopy < ~/.ssh/id_ed25519.pub
  1. Open GitHub.com → Click profile icon → Settings → SSH and GPG keys.
  2. Click New SSH key → Title: "MacBook Pro".
  3. Paste the key into the box → Click Add SSH key.
