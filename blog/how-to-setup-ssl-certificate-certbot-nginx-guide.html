How to Set Up Free Let's Encrypt SSL with Certbot & Nginx (2026 Guide)

Published: November 2026 • 10 min read • By SSH Desktop Engineering Team

Running an unencrypted HTTP website in 2026 is no longer an option. Google Chrome and Safari flag plain HTTP sites as "Not Secure", modern APIs require HTTPS, and search engines penalize unencrypted websites in search rankings.

Fortunately, the days of paying hundreds of dollars for commercial SSL/TLS certificates are long gone. Thanks to the Electronic Frontier Foundation's Let's Encrypt Certificate Authority and Certbot, you can obtain and automate trusted SSL certificates in under two minutes for free.

In this guide, you will learn the exact steps to install Certbot on Ubuntu/Debian, provision an SSL certificate for Nginx, configure automatic HTTP-to-HTTPS redirects, and manage SSL certificates visually.

Prerequisites

  1. A registered domain name (e.g. example.com).
  2. DNS A records for example.com and www.example.com pointing to your server's public IP address.
  3. Nginx installed with port 80 (HTTP) and port 443 (HTTPS) open in your firewall (e.g. sudo ufw allow 'Nginx Full').

Step 1: Verify Nginx Server Block

Before running Certbot, verify that your Nginx configuration contains a valid server_name directive:

sudo nano /etc/nginx/sites-available/example.com
server {
listen 80;
listen [::]:80;
server_name example.com www.example.com;
root /var/www/example.com/html;
index index.html index.htm index.nginx-debian.html;
}

Test Nginx syntax and reload:

sudo nginx -t && sudo systemctl reload nginx

Step 2: Install Certbot and the Nginx Plugin

Install Certbot and the official Nginx integration package:

# Ubuntu / Debian:
sudo apt update
sudo apt install -y certbot python3-certbot-nginx

# CentOS / RHEL / AlmaLinux:
sudo dnf install -y certbot python3-certbot-nginx

Step 3: Obtain and Install the SSL Certificate

Run Certbot with the --nginx flag. Certbot automatically inspects your Nginx server blocks, handles the ACME cryptographic challenge, downloads your certificates, and reconfigures Nginx to use them:

sudo certbot --nginx -d example.com -d www.example.com

Interactive Prompts:

  1. Enter email address: Enter your admin email for urgent renewal notices and security advisories.
  2. Terms of Service: Type Y and press Enter.
  3. Share Email with EFF: Choose Y or N.
  4. HTTPS Redirection: Choose whether to automatically redirect all HTTP traffic to HTTPS (Option 2: Redirect - Make all requests redirect to secure HTTPS access is recommended!).

Certbot updates your Nginx configuration automatically:

Successfully received certificate.
Certificate is saved at: /etc/letsencrypt/live/example.com/fullchain.pem
Key is saved at: /etc/letsencrypt/live/example.com/privkey.pem
Congratulations! You have successfully enabled HTTPS on https://example.com

Step 4: Test Automatic Certificate Renewal

Let's Encrypt certificates expire after 90 days. Certbot installs a systemd timer (certbot.timer) that runs twice daily and automatically renews certificates that are within 30 days of expiration.

Test the automated renewal mechanism with a dry run:

sudo certbot renew --dry-run

If it concludes with "Congratulations, all simulated renewals succeeded", your website will stay secured with SSL indefinitely without any manual intervention!
