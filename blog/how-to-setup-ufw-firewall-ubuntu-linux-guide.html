How to Set Up UFW Firewall on Ubuntu Linux: Complete 2026 Guide

Published: November 2026 • 9 min read • By SSH Desktop Engineering Team

Every Linux server exposed to the public internet needs an active host firewall. While the Linux kernel includes the powerful iptables and nftables packet filtering frameworks, their raw command syntax is notoriously complex.

On Ubuntu and Debian distributions, UFW (Uncomplicated Firewall) provides a clean, user-friendly command-line wrapper designed to make configuring network rules intuitive and safe.

In this guide, you will learn the exact sequence to configure UFW, establish default security policies, rate-limit brute-force attackers, and manage firewall rules visually with SSH Desktop.

Step 1: Check Current UFW Status

By default on fresh Ubuntu cloud servers, UFW is installed but inactive:

sudo ufw status verbose

If it says Status: inactive, proceed to Step 2.

Step 2: Set Default Policies (Deny Inbound, Allow Outbound)

The fundamental foundation of firewall security is default-deny: block all incoming connection attempts by default, while allowing your server to make outgoing requests (e.g. apt update, external API calls):

sudo ufw default deny incoming
sudo ufw default allow outgoing

Step 3: Allow SSH Connections (Prevent Self-Lockout!)

Crucial Warning: If you enable UFW before opening your SSH port, your active SSH session will be severed and you will be completely locked out of your server!

Open standard port 22:

sudo ufw allow 22/tcp comment 'Standard SSH'

Or if you changed your SSH daemon to listen on a custom port like 2222:

sudo ufw allow 2222/tcp comment 'Custom SSH'

Rate-Limiting SSH Brute Force Attacks:

Instead of a generic allow, you can use limit on SSH. This automatically blocks IP addresses that make 6 or more connection attempts within 30 seconds:

sudo ufw limit ssh

Step 4: Allow Essential Web & Application Services

# Allow HTTP (port 80):
sudo ufw allow 80/tcp comment 'HTTP Web'

# Allow HTTPS (port 443):
sudo ufw allow 443/tcp comment 'HTTPS Secure Web'

# Or use pre-configured Nginx profile:
sudo ufw allow 'Nginx Full'

Allowing Access from a Specific IP Address:

If you have private internal services (e.g. database port 5432 or 3306) that should only be accessible from your home or office IP:

sudo ufw allow from 203.0.113.85 to any port 5432 proto tcp comment 'PostgreSQL from Office'

Step 5: Enable UFW

Once your SSH port is verified, enable the firewall:

sudo ufw enable

Press y when prompted. UFW is now active and will automatically enforce these rules across system reboots!

Step 6: Deleting Rules & Disabling UFW

To remove an obsolete rule, list all rules with their numeric indexes:

sudo ufw status numbered

Output:

[ 1] 22/tcp ALLOW IN Anywhere
[ 2] 80/tcp ALLOW IN Anywhere
[ 3] 443/tcp ALLOW IN Anywhere

Delete rule number 2:

sudo ufw delete 2
