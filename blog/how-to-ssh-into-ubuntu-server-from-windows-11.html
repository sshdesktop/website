How to SSH into Ubuntu Server from Windows 11 & 10 (2026 Complete Guide)

Published: November 2026 • 8 min read • By SSH Desktop Engineering Team

Managing a remote Ubuntu Linux server from a Windows 11 machine is one of the most fundamental tasks for software developers, DevOps engineers, and system administrators. Years ago, this required third-party tools like PuTTY with cumbersome separate PuTTYgen key converters and Pageant agents.

In 2026, Windows 11 natively supports the full OpenSSH stack out of the box, and modern graphical tools like SSH Desktop allow you to combine command-line power with visual SFTP file editing, Docker management, and encrypted tunnels.

In this comprehensive guide, we walk through every step to establish a fast, rock-solid, and secure SSH connection from Windows 11 to an Ubuntu server (24.04 LTS, 22.04 LTS, or 20.04).

Prerequisites: What You Need

  • Remote Ubuntu Server IP Address (e.g., 192.168.1.100 on your local network, or a public IPv4 / IPv6 from AWS EC2, DigitalOcean, or Hetzner).
  • Ubuntu Username and Password (e.g., ubuntu, root, or your personal account).
  • OpenSSH Server Installed on Ubuntu: By default, Ubuntu Server installs OpenSSH. If it's missing on desktop Ubuntu, install it using sudo apt install openssh-server.

Method 1: Connect via Windows 11 Built-in OpenSSH Client

Windows 11 comes with OpenSSH Client enabled by default. Open Windows Terminal, PowerShell, or Command Prompt and run:

ssh username@your-server-ip

For example, if your username is ubuntu and your server's IP is 198.51.100.25:

ssh ubuntu@198.51.100.25

On your very first connection, OpenSSH will ask you to verify the host key fingerprint:

The authenticity of host '198.51.100.25 (198.51.100.25)' can't be established.
ED25519 key fingerprint is SHA256:abcd1234efgh5678ijkl9012mnop3456qrst7890.
Are you sure you want to continue connecting (yes/no/[fingerprint])?

Type yes and press Enter. Enter your Ubuntu user account password when prompted. You are now inside your remote Ubuntu bash terminal!

Method 2: Set Up Passwordless Ed25519 SSH Keys (Recommended)

Password authentication is vulnerable to brute-force attacks across the public internet. Cryptographic SSH keys provide vastly superior security and allow instant 1-second logins.

Step 1: Generate an Ed25519 Key Pair on Windows 11

In PowerShell on your Windows PC, execute:

ssh-keygen -t ed25519 -C "windows11-laptop"

Press Enter to accept the default file location (C:\Users\<YourName>\.ssh\id_ed25519). You can optionally enter a passphrase for additional protection.

Step 2: Copy Your Public Key to Ubuntu

Because Windows lacks the Linux ssh-copy-id command natively, you can copy the public key in a single PowerShell command:

type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh ubuntu@your-server-ip "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Enter your password one last time. Now test connecting with your private key:

ssh ubuntu@your-server-ip

You will connect immediately without being prompted for a server password!

Method 3: Configure ~/.ssh/config for 1-Word Aliases

Instead of remembering long IP addresses and custom SSH ports, create a configuration file on Windows at C:\Users\<YourName>\.ssh\config:

Host prod-server
  HostName 198.51.100.25
  User ubuntu
  Port 22
  IdentityFile ~/.ssh/id_ed25519

Now, whenever you want to connect from PowerShell or Windows Terminal, simply type:

ssh prod-server

Troubleshooting Common Ubuntu SSH Errors

1. "Connection Refused on Port 22"

This indicates that the OpenSSH daemon is either stopped or blocked by a firewall on Ubuntu. Run the following on the Ubuntu server console:

sudo systemctl enable --now ssh
sudo ufw allow 22/tcp
sudo ufw reload

2. "Permission Denied (publickey)"

Check permissions on the Ubuntu server's .ssh folder:

chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

3. "Host Key Verification Failed"

If your Ubuntu server was recently reinstalled, its fingerprint changed. Clear the old entry in Windows:

ssh-keygen -R your-server-ip
