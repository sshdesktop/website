How to Connect to Remote MySQL & MariaDB Over SSH Tunnel (2026 Guide)

Published: November 2026 • 10 min read • By SSH Desktop Engineering Team

MySQL and MariaDB power over 70% of the web's database workloads, from WordPress and Magento to custom Node.js, Go, and Laravel applications.

When administering a remote database, the tempting shortcut is opening port 3306 in UFW and changing bind-address = 0.0.0.0 in my.cnf. This is one of the most dangerous database practices in production environments.

By creating an encrypted SSH Tunnel, you can inspect, query, and manage remote MySQL databases from your local desktop tools (MySQL Workbench, DBeaver, TablePlus, or SSH Desktop's visual Database Studio) while keeping port 3306 locked strictly to localhost.

Why Public MySQL Port 3306 Is a Critical Vulnerability

The Dangers of Public Database Exposure:
  • Automated Ransomware Bots: Scripted botnets scan IPv4 ranges for open port 3306, brute-force MySQL root passwords, drop all databases, and leave a Bitcoin ransom note.
  • Plaintext Transmission: Default MySQL protocol communication does not enforce strict TLS certificate validation. Passwords and sensitive customer tables can be sniffed in transit across unencrypted public networks.
  • Compliance Failures: SOC2, ISO 27001, and PCI-DSS strictly forbid publicly exposed database listeners without hardened multi-factor gateway controls.

Method 1: Terminal CLI (Local Port Forwarding)

Open your terminal and establish a local port forward:

ssh -N -L 3306:localhost:3306 user@your-server-ip

Handling Local Port 3306 Conflicts:

If you already have MySQL running locally on your laptop, port 3306 will be occupied. Forward to port 3307 instead:

ssh -N -L 3307:localhost:3306 user@your-server-ip

Now test connecting with the official MySQL client from a second terminal window:

mysql -h 127.0.0.1 -P 3307 -u db_user -p

Method 2: Configuring MySQL Workbench

MySQL Workbench has native SSH tunneling support built directly into its connection wizard:

  1. Open MySQL Workbench and click the + icon to add a new MySQL Connection.
  2. In Connection Method, select Standard TCP/IP over SSH.
  3. SSH Hostname: Your server's public IP address (e.g. 198.51.100.42:22).
  4. SSH Username: Linux user (e.g. ubuntu).
  5. SSH Keyfile: Browse to your private key (~/.ssh/id_ed25519).
  6. MySQL Hostname: 127.0.0.1 (from the server's local perspective).
  7. MySQL Server Port: 3306.
  8. Username: Your remote MySQL user (e.g. app_user).
  9. Click Test Connection. Workbench establishes the SSH pipe and connects seamlessly!

Method 3: Configuring DBeaver

  1. Create a New Database Connection → Select MySQL.
  2. In the Main tab: Host localhost, Port 3306, Database name, and MySQL credentials.
  3. Switch to the SSH tab and check Use SSH Tunnel.
  4. Enter your remote server IP, SSH port 22, SSH username, and select your private key.
  5. Click Test Connection.

Method 4: Connecting from Application Code (Node.js & Python)

Once your tunnel is running on 127.0.0.1:3307, your local development code can connect just like a local database:

Python (PyMySQL / SQLAlchemy):

import pymysql

connection = pymysql.connect(
host='127.0.0.1',
port=3307,
user='db_user',
password='secret_password',
database='production_db'
)

Node.js (mysql2):

const mysql = require('mysql2/promise');

const pool = mysql.createPool({
host: '127.0.0.1',
port: 3307,
user: 'db_user',
password: 'secret_password',
database: 'production_db'
});
