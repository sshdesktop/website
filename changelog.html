Release History

SSH Desktop Changelog

Follow every new release, performance enhancement, and security upgrade in SSH Desktop.

v2.4.2 Latest Stable
November 2026

✨ Highlights & Improvements

  • Optimized Memory Footprint: Reduced client-side baseline RAM usage by 24% during high-throughput split-pane terminal sessions.
  • Monaco Code Editor Update: Upgraded remote SFTP code editing engine with updated syntax highlighters for YAML, Rust, Go, Python, and TypeScript.
  • Enhanced Docker Log Streaming: Live stdout/stderr log inspection now includes ANSI 24-bit TrueColor parsing with regex keyword highlight matching.
  • macOS Sonoma Glass Shell: WebGL window blur shaders now run at 60 FPS on integrated Intel and Snapdragon ARM64 graphics.
v2.4.0 Feature Release
October 2026

🚀 New Features

  • Self-Hosted Web Mode: Run SSH Desktop as a headless systemd service accessible from Chrome, Safari, and Firefox on frontend port 2222 and backend port 2020.
  • Universal Database Studio (App 6): Native visual query builder with automated ephemeral SSH tunneling for PostgreSQL, MySQL, Redis, and SQLite.
  • Hardware-Accelerated PTY: Added horizontal and vertical split panes with independent session multiplexing.
v2.3.0 Feature Release
September 2026

🔒 Security & SFTP

  • Native Credential Vaults: Secure key storage backed by Windows DPAPI and Apple macOS Keychain.
  • Dual-Pane SFTP Manager: Drag-and-drop file transfers with in-place remote .zip, .tar.gz, and .tar.bz2 extraction.
  • Visual UFW & Iptables Manager: One-click port rules and source subnet access restrictions with SSH lockout protection.
v2.2.0 Infrastructure
August 2026

⚙️ System Administration Suite

  • Systemd Services Manager: Graphical start, stop, restart, enable, disable, and live journalctl log inspector for systemd units.
  • Linux Process Explorer: Htop-style visual process table with CPU%, Memory%, kill signals, and tree views.
  • RDP over SSH Tunnel Manager: Encrypted tunneling for Windows Remote Desktop (port 3389) and Linux XRDP.
