Admin Reference

The Ultimate Linux Server & SSH Cheat Sheet

Essential command syntax for sysadmins and developers: OpenSSH flags, Ed25519 key generation, port forwarding tunnels, permissions, systemd services, and UFW firewalls.

🔑 SSH Key Generation & Distribution

# Generate modern Ed25519 keypair ssh-keygen -t ed25519 -C "admin@sshdesktop" # Copy public key to remote server ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server.example.com # Fix strict OpenSSH permissions chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys chmod 600 ~/.ssh/id_ed25519 && chmod 644 ~/.ssh/id_ed25519.pub

🔀 SSH Port Forwarding & Tunneling Syntax

# Local Port Forwarding (-L): Access remote database locally ssh -L 5432:localhost:5432 user@server.example.com # Remote Port Forwarding (-R): Expose local dev server to remote host ssh -R 8080:localhost:3000 user@server.example.com # Dynamic SOCKS5 Proxy (-D): Route browser traffic through remote VPS ssh -D 1080 -N -f user@server.example.com # Connect through Bastion / Jump Host (ProxyJump) ssh -J bastion.example.com user@internal-node.example.com

⚙️ Systemd Service Management Commands

# Check service status, start, restart, reload sudo systemctl status nginx sudo systemctl restart nginx sudo systemctl reload nginx # Enable service to start on system boot sudo systemctl enable nginx # Inspect failed services across entire system sudo systemctl --failed # Stream live real-time service logs sudo journalctl -u nginx -f --tail=100

🛡️ Visual UFW & Network Port Commands

# Check UFW firewall status with rule numbers sudo ufw status numbered # Allow SSH, HTTP, and HTTPS traffic sudo ufw allow 22/tcp sudo ufw allow 80/tcp sudo ufw allow 443/tcp # Limit SSH brute force attempts (rate limiting) sudo ufw limit 22/tcp # Check all listening TCP/UDP ports and process names sudo ss -tulpn
