FAQ

Frequently Asked Questions

How does SSH Desktop connect to Docker without an agent?

When you establish an SSH session, SSH Desktop communicates directly with the local Docker daemon socket at /var/run/docker.sock using standard UNIX domain socket streaming over SSH channels. This eliminates the need to install or update any third-party container management agents.

Can I manage containers on remote cloud VPS instances?

Yes. Whether your server is on AWS EC2, DigitalOcean, Hetzner, Linode, or a local homelab server, as long as you have SSH access and your user belongs to the docker group, you can manage all containers seamlessly.

Does SSH Desktop support viewing Docker container stats?

Yes! You can monitor live CPU percentage, memory consumption in megabytes, network I/O, and block I/O per container in real time.
