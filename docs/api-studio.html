🔌 API Studio (REST/GraphQL/WS)

Test private APIs and internal microservices over secure SSH tunnels without exposing ports. Supports REST (GET/POST/PUT/DELETE), GraphQL, and WebSockets.

Figure: Real-time visual interface of API Studio (REST/GraphQL/WS) in SSH Desktop.

What is this Application & Why Do You Need It?

API Studio is a built-in REST, GraphQL, and WebSocket API client. Because it integrates directly with SSH Desktop's tunneling engine, it allows you to test private microservices and APIs running strictly on 127.0.0.1 or internal VPC subnets without exposing them to the public internet.

Testing private internal APIs usually requires installing Postman, setting up manual SSH tunnels on your host machine, and configuring environment variables. API Studio provides a zero-setup testing studio that automatically proxies requests over your active SSH connection.

Legacy Tools Replaced: Postman, Insomnia, curl CLI, Hopscotch

🖥️ Interface Overview & Visual Controls

The API Studio is a built-in Postman and Insomnia alternative for testing private backend APIs directly over SSH. The top request bar includes an HTTP Method Selector (GET, POST, PUT, PATCH, DELETE, OPTIONS), an URL input (supports http://localhost:3000/api/...), and a Send button. Tabs beneath the request bar configure Query Params, Headers, Body (JSON, Form Data, GraphQL, Raw), and Auth (Bearer Token, Basic Auth). The response viewer on the right displays HTTP status codes, response time in ms, response body with JSON syntax highlighting, and response headers.

Key Capabilities & Features

  • Automated Tunnel Routing: Requests to http://localhost:PORT automatically route through the active SSH session.
  • 7 HTTP Methods: GET, POST, PUT, PATCH, DELETE, HEAD, and OPTIONS with custom headers, query params, and JSON/Form bodies.
  • Code Snippet Generator: Convert any request with 1 click into cURL, Fetch, Python requests, or Go code snippets.
  • GraphQL Explorer: Run GraphQL queries and mutations with autocompletion, schema inspection, and variable substitution.
  • Live WebSocket Tester: Connect to internal WebSocket endpoints, send messages, and monitor incoming event streams.

📋 Prerequisites & Remote Host Requirements

  • An active SSH connection to the server hosting your API.
  • API services listening on localhost (e.g. 127.0.0.1:8000) or an internal network.

Step-by-Step How-To Tutorial

1. Making Your First Request

Open API Studio. Select the HTTP method (e.g. GET) and enter the URL: http://localhost:3000/api/users. Click Send. The response status (200 OK), response time, and JSON payload appear immediately.

2. Sending JSON Bodies and Custom Headers

Select POST. Switch to the Body tab and enter your JSON payload. Add authentication headers (e.g. Authorization: Bearer <token>) in the Headers tab.

3. Generating Code Snippets

Click Code Snippet in the top-right toolbar. Select your language (cURL, JavaScript Fetch, Python, or Go) to copy ready-to-run code for your integration.

💡 Pro-Tips & Best Practices

  • Direct Localhost Access: Test internal microservices running on http://127.0.0.1:8080 without deploying ngrok tunnels or exposing unauthenticated development ports to the public internet.
  • Auto-Formatted JSON Response: Responses are automatically parsed, indented, and color-coded with collapsible JSON tree nodes for easy inspection.
  • Generate cURL & Fetch Snippets: Click the "Code Snippet" button to copy ready-to-run cURL, Python requests, or JavaScript fetch code based on your current request.
  • Request History & Collections: Save frequent API requests into organized workspace collections to share across your development team.

Under the Hood: Linux Commands & Architecture

Requests are executed through an internal Direct-TCPIP forwarder managed by the Rust backend using the reqwest HTTP client and tokio-tungstenite WebSocket driver. No data travels over public internet routes.

Primary Commands / Virtual Files Executed Over SSH:
SSH local port forwarding + reqwest HTTP client + WebSocket client

❓ Troubleshooting & Frequently Asked Questions

Request timeout: ECONNREFUSED 127.0.0.1:3000

Ensure the backend server application is actively running on port 3000 on the remote host by checking the Listening Ports tab in Network Auditor.

CORS errors on API responses

CORS only applies to browser environments. API Studio executes requests from the native Rust client directly over the SSH tunnel, completely bypassing browser CORS restrictions.
