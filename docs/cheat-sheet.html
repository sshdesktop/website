📋 Linux Server & SSH Cheat Sheet

The ultimate sysadmin quick reference card. Essential OpenSSH commands, Ed25519 keypair generation, port forwarding tunnel syntax, systemd controls, and firewall rules.

Figure: Real-time visual interface of Linux Server & SSH Cheat Sheet in SSH Desktop.

What is this Application & Why Do You Need It?

The Linux Server & SSH Cheat Sheet is a curated reference guide of the most critical terminal commands used in day-to-day server administration. It provides exact command syntax for SSH keygen, port forwarding, systemd management, and security auditing.

Even seasoned sysadmins forget exact flag syntax for tunnel forwarding (-L vs -R vs -D) or octal permissions. This cheat sheet serves as an instant reference companion.

Step-by-Step How-To Tutorial

1. SSH Key Management & Permissions Syntax

Essential key generation and permission commands:
# Generate Ed25519 key ssh-keygen -t ed25519 -C "admin@sshdesktop" # Copy public key to server ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server # Strict file permissions chmod 700 ~/.ssh chmod 600 ~/.ssh/authorized_keys chmod 600 ~/.ssh/id_ed25519 chmod 644 ~/.ssh/id_ed25519.pub

2. SSH Port Forwarding & Tunneling Syntax

Quick reference for Local, Remote, and Dynamic forwarding:
# Local Forwarding: ssh -L [local_port]:[remote_host]:[remote_port] ssh -L 5432:localhost:5432 user@server # Remote Forwarding: ssh -R [remote_port]:[local_host]:[local_port] ssh -R 8080:localhost:3000 user@server # Dynamic SOCKS5 Proxy ssh -D 1080 -N -f user@server # Multi-hop Jump Host ssh -J jump.example.com user@target-node

3. Systemd Unit Controls

Managing services and timers:
sudo systemctl start nginx sudo systemctl stop nginx sudo systemctl restart nginx sudo systemctl reload nginx sudo systemctl enable nginx sudo systemctl status nginx sudo systemctl --failed sudo journalctl -u nginx -f --tail=100

4. Visual Equivalent in SSH Desktop

Every command in this cheat sheet is natively available as a one-click visual action in SSH Desktop's 25 native applications (Systemd Services, Database Studio, Firewall Manager, and Tunnels).

💡 Pro-Tips & Best Practices

  • Use Bastion Directives: Add ProxyJump jump-server to your ~/.ssh/config for permanent multi-hop routing.
  • Test Configs Before Reload: Always run nginx -t or visudo -c before reloading system services.

❓ Troubleshooting & Frequently Asked Questions

Permission denied (publickey) despite key copied

Check /var/log/auth.log or run sudo journalctl -u ssh on the server to see why sshd rejected the key (often due to loose directory permissions on the home folder).
