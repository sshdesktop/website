🖥️ macOS Sonoma Desktop Shell

Master the macOS Sonoma-inspired cloud desktop interface. Learn how to manage floating windows, snap panes, launch apps with Spotlight (Cmd+K), and customize your workspace.

Figure: Real-time visual interface of macOS Sonoma Desktop Shell in SSH Desktop.

What is this Application & Why Do You Need It?

The Cloud Desktop Shell is the central visual interface of SSH Desktop. Inspired by the sleek aesthetics and ergonomics of macOS Sonoma, it provides a native desktop experience inside a single application window: floating draggable windows, a bottom application dock with badges, a top menu bar with server telemetry, and a universal Spotlight launcher.

Managing servers in raw terminals often leads to window clutter, lost tabs, and complex tmux sessions. The Cloud Desktop shell gives you a spatial mental model: keep Docker in one window, Terminal in another, File Manager on the side, and live System Monitor pinned to the top, all neatly arranged and saved across sessions.

Legacy Tools Replaced: Messy multi-window terminal clutter, tmux complex keybindings

🖥️ Interface Overview & Visual Controls

The macOS Sonoma Desktop Shell provides a full multi-window desktop interface for remote servers. The Top Menu Bar features the Apple-style Server Switcher, active app menus, real-time CPU/RAM meters, and system time. The Desktop Area supports wallpaper customization, desktop sticky notes, and freeform floating windows with macOS traffic light controls (Close, Minimize, Zoom). The Dock at the bottom organizes all 25 native apps with bouncing launch animations and active indicator dots.

Key Capabilities & Features

  • Floating Window Manager: Move, resize, minimize, maximize, and tile application windows with fluid physics.
  • Window Snapping: Drag windows to screen edges to snap left 50%, right 50%, top, or full screen.
  • macOS Sonoma Dock: Dock with app launching, running indicators, notification badges, and dock magnification.
  • Spotlight Launcher (Cmd+K): Instant keyboard-driven search to launch apps, switch servers, or run snippets.
  • Top Menu Bar: Displays real-time server hostname, CPU/RAM telemetry pills, uptime, and quick settings.

📋 Prerequisites & Remote Host Requirements

  • Active connection to any Linux server in SSH Desktop.
  • Works identically on desktop clients and browser Web Mode.

Step-by-Step How-To Tutorial

1. Launching Applications

Launch any of the 25 native applications in three ways:
  • From the Dock: Click any icon in the bottom dock. Hovering reveals app previews.
  • From Spotlight (Recommended): Press Cmd/Ctrl + K, type the app name (e.g. docker, terminal, database), and hit Enter.
  • From the Top Menu: Click the Apps dropdown in the top-left menu bar.

2. Managing and Snapping Windows

Windows behave just like native macOS/Windows windows:
  • Window Controls: Click red to close, yellow to minimize to dock, green to maximize.
  • Split Snapping: Drag a window to the left screen edge to snap it to the left 50%. Drag another to the right to snap side-by-side.
  • Focus Management: Clicking anywhere inside a window brings it to the top z-index.

3. Multi-Server Switching

When managing multiple servers, click the server badge in the top menu bar or press Cmd/Ctrl + Shift + S. Select another server to instantly switch the desktop context while keeping all your windows and background tasks alive.

💡 Pro-Tips & Best Practices

  • Spotlight Launcher (Cmd/Ctrl + K): Press Cmd/Ctrl + K anywhere on the desktop to instantly search and launch any app, server connection, or command snippet.
  • Window Snapping: Drag any window to the screen edges or corners to snap it into 50% split view or 25% quadrant tiling.
  • Multi-Server Switching: Switch between connected servers instantly from the top-left menu bar without closing your open application windows.
  • Workspace Presets: Save your favorite window arrangements (e.g. "Dev: Terminal + Monaco + Logs" or "Ops: Docker + Monitor + Firewall") to reopen them with one click.

Under the Hood: Linux Commands & Architecture

Implemented in React 19 using CSS transforms and hardware-accelerated composite layers. Window positions, sizes, and active tabs are persisted in local indexedDB/localStorage so that your exact workspace layout is restored when you reconnect.

❓ Troubleshooting & Frequently Asked Questions

Window disappeared off screen after display resize

Press Cmd/Ctrl + Option + 0 (Zero) to cascade and center all open application windows within the current visible viewport.

Dock hiding behind floating windows

Toggle "Always Keep Dock on Top" in Desktop Preferences or hover your cursor at the bottom edge of the screen to reveal the Dock.
