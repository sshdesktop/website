Step-by-Step How-To Tutorial

1. How does SSH Desktop manage servers without installing agents?

Traditional web control panels (cPanel, Webmin, Cockpit, Portainer) run persistent daemon processes on your server. SSH Desktop works entirely through standard OpenSSH: it establishes an encrypted SSH session and executes native Linux commands (such as systemctl, docker, ufw, and /proc readers). All parsing, GUI rendering, and windowing happen locally on your PC, leaving zero background footprint on your server.

2. Where are my SSH keys and credentials stored?

Your private keys, passwords, and passphrases never leave your local machine. Passphrases are stored in your operating system's hardware-encrypted credential vault: macOS Keychain, Windows Credential Manager (DPAPI), or Linux Secret Service. SSH Desktop has zero telemetry, zero analytics, and zero cloud accounts.

3. Do I need to open any extra firewall ports on my server?

No. All 25 applications communicate exclusively through your existing OpenSSH port (port 22 by default). You never need to open insecure web ports (like 9090, 10000, or 9443) on your server.

4. What Linux distributions are supported?

SSH Desktop supports any Linux server running OpenSSH 7.0 or newer. Verified distributions include Ubuntu (18.04 to 24.04 LTS), Debian (10 to 13), Red Hat Enterprise Linux / CentOS / Rocky / AlmaLinux (7 to 9), Fedora, Arch Linux, Alpine Linux, Amazon Linux, and openSUSE.
