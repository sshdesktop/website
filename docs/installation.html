Getting Started & Core

💿 Installation & Platform Support

Comprehensive installation and cross-platform setup guide for SSH Desktop. Learn how to install and update native desktop binaries for macOS, Windows 11/10, and Linux distributions.

Figure: Real-time visual interface of Installation & Platform Support in SSH Desktop.

What is this Application & Why Do You Need It?

SSH Desktop is distributed as native pre-compiled binaries optimized for each major operating system. On macOS, it runs natively on both Apple Silicon (M1, M2, M3, M4) and Intel x86_64 architectures. On Windows, it provides a lightweight MSI installer and standalone executable with Windows Terminal keybinding parity. On Linux, it supports portable AppImage, Debian/Ubuntu DEB, Fedora/RHEL RPM, and Arch Linux packages.

Many developer tools rely on bloated Electron runtimes that bundle entire Chromium web browsers, consuming hundreds of megabytes of RAM just to display a terminal. SSH Desktop is compiled in Rust using native operating system webviews (WebKit on macOS, WebView2 on Windows, WebKitGTK on Linux), ensuring launch times under 200ms and an idle RAM footprint under 45 MB.

Legacy Tools Replaced: Complex terminal package setups, bloated Electron installers

🖥️ Interface Overview & Visual Controls

The Installation & Setup Window confirms that native OS webview runtimes and hardware acceleration are available. On first launch, it offers a quick setup wizard allowing you to select your preferred desktop theme (macOS Dark, Midnight OLED, or Tokyo Night), import existing SSH hosts from ~/.ssh/config, and configure default terminal typography.

Key Capabilities & Features

  • Native Universal Binaries: Zero emulation overhead on Apple Silicon M1-M4 chips and modern 64-bit processors.
  • Sub-15MB Binary Size: Compact download size that installs in seconds without downloading gigabytes of dependencies.
  • Zero Background Daemons: Installs cleanly into standard user directories without installing background update services or kernel extensions.
  • Seamless Auto-Updates: Cryptographically signed update channels notify you of new releases and apply patches with a single click.

📋 Prerequisites & Remote Host Requirements

  • macOS 11 (Big Sur) or newer (Universal binary for Apple Silicon M1-M4 & Intel).
  • Windows 10 (version 1809+) or Windows 11 (64-bit) with Microsoft Edge WebView2 runtime (pre-installed on Windows 11).
  • Linux: Any modern distribution with glibc 2.31+ and webkit2gtk (Ubuntu 20.04+, Debian 11+, Fedora 34+, Arch Linux).

Step-by-Step How-To Tutorial

1. Installing on macOS (Apple Silicon & Intel)

Download the universal .dmg package from the official download portal. Double-click the downloaded disk image and drag the SSH Desktop icon into your /Applications directory. On first launch, macOS Gatekeeper verifies the developer signature automatically.

2. Installing on Windows 11 & Windows 10

Download the signed .msi installer or the standalone portable executable. Run the installer and follow the setup wizard. SSH Desktop integrates with Windows Terminal keybindings and utilizes Windows Credential Manager (DPAPI) to protect your SSH keys and passphrases.

3. Installing on Linux Desktops

Choose the package matching your distribution:
  • Universal AppImage: Run chmod +x sshdesktop*.AppImage && ./sshdesktop*.AppImage for instant portable execution.
  • Debian & Ubuntu: Install via sudo dpkg -i sshdesktop*.deb or apt.
  • Fedora & RHEL: Install via sudo rpm -i sshdesktop*.rpm.
  • Arch Linux: Available via the AUR package sshdesktop-bin.

4. Verifying Installation & Automatic Updates

Launch SSH Desktop from your operating system launcher or application menu. The startup screen automatically checks for cryptographically signed updates and displays release notes when new stable versions are released.

💡 Pro-Tips & Best Practices

  • Portable Mode for USB Drives: The Windows standalone portable executable stores preferences in its local directory when a portable.dat file is present.
  • Linux Desktop Integration: Installing the .deb or .rpm automatically creates desktop launcher shortcuts and registers the ssh:// URL protocol handler.
  • Apple Silicon Optimization: The macOS Universal binary executes natively on M1, M2, M3, and M4 Apple Silicon with zero Rosetta 2 translation overhead.

❓ Troubleshooting & Frequently Asked Questions

macOS Gatekeeper warning: "App cannot be opened"

Right-click the SSH Desktop app in Finder, select Open, and click Open in the confirmation modal. This approves the application signature in macOS security settings.

Windows: Missing WebView2 runtime error

Windows 10 installations without the evergreen Microsoft Edge WebView2 runtime can install it directly via Microsoft's official Evergreen Bootstrapper installer.
