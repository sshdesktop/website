Getting Started & Core

⚡ 3-Minute Quickstart Guide

From zero to visual server desktop in 3 minutes. Fast-track onboarding guide to installing SSH Desktop, importing host profiles, and launching applications.

Figure: Real-time visual interface of 3-Minute Quickstart Guide in SSH Desktop.

What is this Application & Why Do You Need It?

The 3-Minute Quickstart is designed for busy developers and sysadmins who want to get up and running immediately. It covers downloading the binary, auto-importing existing hosts, and launching your first desktop session in four simple steps.

Getting started with new infrastructure tools shouldn't require hours of reading. This guide gets you connected and productive in less than 180 seconds.

Legacy Tools Replaced: Lengthy manual onboarding, complex CLI configuration

🖥️ Interface Overview & Visual Controls

The Quickstart Welcome Interface introduces the desktop layout: Dock at the bottom, top menu bar with server switcher, and the central workspace for floating, snapping windows.

Key Capabilities & Features

  • Sub-3-Minute Setup: Fast, frictionless onboarding with automated configuration discovery.
  • Automatic ~/.ssh/config Import: Instantly detects and imports your existing OpenSSH hosts.
  • Keyboard-First Navigation: Master the core Cmd+K launcher in seconds.

📋 Prerequisites & Remote Host Requirements

  • macOS, Windows, or Linux desktop PC.
  • Any remote Linux server with SSH credentials.

Step-by-Step How-To Tutorial

1. Download & Launch the Native Binary

Download for your OS (macOS DMG, Windows MSI, or Linux AppImage). Launch the application.

2. Add or Import Your Server Connection

Click + New Connection or click Import ~/.ssh/config. Enter your server hostname or IP address, username, and select your private key.

3. Experience the macOS Cloud Desktop

Click Connect. Your server's visual desktop shell launches immediately with a floating window manager, top menu bar, and macOS-style Dock.

4. Master the Spotlight Launcher (Cmd/Ctrl + K)

Press Cmd/Ctrl + K to search across apps, server profiles, and shell snippets. Type docker or logs to jump into any tool instantly.

💡 Pro-Tips & Best Practices

  • Pin Favorite Apps: Drag frequently used applications to the front of the Dock for instant access upon connecting.
  • Multi-Server Switching: Connect to multiple servers simultaneously and switch between them using the top-left menu bar.

Under the Hood: Linux Commands & Architecture

Parses local OpenSSH configuration files using an internal Rust tokenizer and initializes the encrypted session over port 22.

Primary Commands / Virtual Files Executed Over SSH:
ssh connection, ~/.ssh/config parser, Spotlight launcher

❓ Troubleshooting & Frequently Asked Questions

Cannot find where my SSH private keys are located

Standard OpenSSH keys are stored in ~/.ssh/ (or C:\Users\Username\.ssh\ on Windows). Click "Browse" in the connection modal to select your key.
