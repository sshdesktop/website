⚙️ Settings, Themes & Preferences

Complete guide to configuring SSH Desktop preferences. Customize themes, editor color schemes, terminal fonts, ligature rendering, and low-bandwidth telemetry.

Figure: Real-time visual interface of Settings, Themes & Preferences in SSH Desktop.

What is this Application & Why Do You Need It?

The Settings & Preferences workspace (based on AppSettings.tsx) provides granular control over the SSH Desktop environment. It lets you customize visual themes (macOS Dark, Midnight OLED, Tokyo Night, Dracula, Solarized), configure hardware-accelerated terminal typography, set default SSH parameters, and adjust background telemetry polling.

Different development workflows require tailored environments: night shifts benefit from high-contrast OLED dark themes, slower satellite connections need reduced telemetry bandwidth, and code readability improves with specialized programmer fonts like JetBrains Mono and Fira Code.

Legacy Tools Replaced: Clunky config files, terminal theme hacking, manual font overrides

🖥️ Interface Overview & Visual Controls

The Preferences Modal is organized into 5 intuitive tabs: General (startup behavior, window snapping, auto-reconnect), Appearance (themes, window translucency, dock icon magnification), Terminal (font family, font size, cursor style, scrollback lines), Network & SSH (default ports, keep-alive intervals, cipher suites), and Security (credential vault, auto-lock timer).

Key Capabilities & Features

  • Curated Color Themes: Switch between macOS Sonoma Dark, Midnight OLED, Tokyo Night, GitHub Dark, and Nord with instant preview.
  • Custom Typography & Ligatures: Choose your favorite font family, font size, line height, and toggle programming ligature rendering.
  • Low-Bandwidth Mode: Throttle telemetry polling from 1s to 5s to conserve network data over mobile tethering or high-latency satellite connections.
  • Auto-Lock & Security Timeout: Automatically minimize or lock active server windows after a configurable period of keyboard/mouse inactivity.

📋 Prerequisites & Remote Host Requirements

  • SSH Desktop application running locally.
  • Optional: Custom monospace fonts installed on your local operating system.

Step-by-Step How-To Tutorial

1. Accessing Application Preferences

Open Preferences by clicking SSH Desktop → Preferences in the top menu bar or by pressing Cmd/Ctrl + , anywhere in the application.

2. Selecting Visual Themes

Under the Appearance tab, choose from curated dark themes:
  • macOS Sonoma Dark (Default): Sleek, semi-transparent frosted glass aesthetic matching modern macOS.
  • Midnight OLED: Pure true-black background (#000000) for OLED laptops and maximum battery conservation.
  • Tokyo Night & Dracula: Vibrant syntax-highlighted themes designed for prolonged coding sessions.

3. Configuring Terminal Fonts & Ligatures

Switch to the Terminal tab to select your installed monospace font (e.g. JetBrains Mono, Fira Code, Cascadia Code, Menlo). Toggle the Enable Font Ligatures checkbox to render arrows (→, =>) and operators cleanly.

4. Optimizing Telemetry & Low-Bandwidth Mode

In the Telemetry tab, select your polling frequency. If working over 4G/5G tethering or high-latency satellite links, enable Low Bandwidth Mode to compress SFTP listings and poll CPU metrics every 5 seconds instead of every second.

💡 Pro-Tips & Best Practices

  • Increase Scrollback Buffer: Increase terminal scrollback lines from 5,000 to 20,000 in Terminal settings if you frequently inspect lengthy compilation or deployment logs.
  • Auto-Reconnect Watchdog: Enable "Automatic Reconnect on Network Resume" so SSH Desktop restores your server sessions seamlessly when waking your laptop from sleep.
  • Cursor Customization: Choose between Block, Underline, and Bar cursor styles with optional blinking in the Terminal preferences.

Under the Hood: Linux Commands & Architecture

Preferences are persisted locally in a sandboxed JSON configuration store. No configuration data is ever uploaded to external servers.

❓ Troubleshooting & Frequently Asked Questions

Custom font not appearing in font dropdown

Ensure the font is installed in your operating system's font manager (Font Book on macOS, Fonts in Windows Settings) and restart SSH Desktop to refresh available system fonts.
