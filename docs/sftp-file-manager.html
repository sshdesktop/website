📁 Dual-Pane SFTP File Manager

High-speed dual-pane SFTP file manager with drag-and-drop transfers, in-place remote archive extraction (.tar.gz, .zip), permissions editor, and recursive file search.

Figure: Real-time visual interface of Dual-Pane SFTP File Manager in SSH Desktop.

What is this Application & Why Do You Need It?

The Dual-Pane SFTP File Manager is an advanced visual file browser tailored for remote server administration. It provides a split-view interface (Local <-> Remote or Remote <-> Remote) with drag-and-drop uploads, instant directory navigation, remote file editing, and direct server-side archive extraction.

Using CLI commands (scp, rsync, tar, chmod) for routine file management is slow and prone to typographical errors. External FTP clients like FileZilla lack server-side archive extraction and don't integrate with your SSH keys or Monaco editor. SSH Desktop combines everything into a single zero-overhead tool.

Legacy Tools Replaced: FileZilla, WinSCP, Cyberduck, Transmit

🖥️ Interface Overview & Visual Controls

The SFTP File Manager features a dual-pane layout for effortless local-to-remote and remote-to-remote file management. The top toolbar provides Back / Forward, Breadcrumb Path Navigation, Search Filter, New Folder, Upload, Download, and View Switcher (Icons, Details List, Columns). Right-clicking any file opens a contextual menu with options to Edit in Monaco, Compress (.tar.gz / .zip), Extract Archive, Change Permissions (Chmod), and View Properties.

Key Capabilities & Features

  • Multiple View Modes: macOS Finder-style Columns view (ColumnsView.tsx), Icons view, List view, and Gallery view.
  • In-Place Remote Archive Engine: Extract `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.zip`, and `.7z` archives directly on the server without downloading them!
  • Spacebar Quick Look: Press Spacebar to instantly preview images, text files, and JSON payloads.
  • Letter Jump Navigation: Type letters on your keyboard to instantly jump to matching files.
  • Visual Permissions Editor: Modify octal file permissions (chmod 755/644) and ownership (chown user:group) with simple checkboxes.

📋 Prerequisites & Remote Host Requirements

  • SFTP subsystem enabled on the remote server (standard in almost all OpenSSH installations).
  • Read/write permissions for directories you wish to modify.

Step-by-Step How-To Tutorial

1. Navigating Directories with Quick Look & Letter Jump

Open the SFTP File Manager. Type any path in the address bar (Cmd+L) or double-click folders. Press Space on any file to open the instant Quick Look preview. Type letters to immediately jump to files matching that letter.

2. Drag-and-Drop Uploads and Downloads

Drag files directly from your computer's native desktop or file explorer into the remote directory pane. The transfer drawer tracks active progress, transfer speed (MB/s), and estimated completion time.

3. In-Place Archive Extraction (.tar.gz / .zip)

Right-click any .tar.gz, .tgz, or .zip file and choose Extract Here or Extract to Folder.... The server unpacks the archive directly on disk in seconds without consuming client network bandwidth.

4. Editing Permissions & Ownership (chmod / chown)

Right-click any file and select Permissions & Properties. Toggle Read, Write, and Execute checkboxes for Owner, Group, and Others. Check "Apply recursively to subdirectories" to batch update permissions.

💡 Pro-Tips & Best Practices

  • In-Place Remote Extraction: Right-click any .tar.gz, .tar.bz2, or .zip file and click "Extract Here" to unpack it instantly on the server without downloading.
  • Visual Chmod Editor: Right-click a file or folder and select "Permissions" to set read, write, and execute permissions with visual checkboxes or octal notation (e.g. 755, 644).
  • Drag-and-Drop Transfers: Drag files directly from your local desktop file explorer into the SFTP file manager to initiate instant background uploads.
  • Hidden Files Toggle (Cmd/Ctrl + H): Quickly show or hide dotfiles (like .env, .htaccess, .git/) with a single shortcut.

Under the Hood: Linux Commands & Architecture

Transfers execute over OpenSSH dedicated SFTP subsystem channel (v3). Server-side archive operations execute optimized native POSIX utilities (tar -xzf, unzip -q) on the host.

Primary Commands / Virtual Files Executed Over SSH:
sftp subsystem, tar -xzf, unzip, chmod, chown, stat

❓ Troubleshooting & Frequently Asked Questions

Permission denied when uploading to /var/www or /etc

Non-root users cannot write to root-owned directories. Use the "Sudo SFTP Mode" toggle in connection settings or upload to your home folder first and move with sudo mv.

Archive extraction fails on remote server

Ensure tar, gzip, or unzip packages are installed on the remote Linux host (sudo apt install tar unzip).
