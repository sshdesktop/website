📌 Desktop Sticky Notes & Scratchpad

Pin colorful markdown sticky notes directly on your remote desktop shell. Keep scratchpads, cheat sheets, IP references, and server notes across sessions.

Figure: Real-time visual interface of Desktop Sticky Notes & Scratchpad in SSH Desktop.

What is this Application & Why Do You Need It?

The Desktop Sticky Notes app provides a lightweight, persistent scratchpad anchored directly to your server's cloud desktop. Create color-coded notes, jot down temporary IP addresses, draft command snippets, track operational to-do lists, and pin critical notes so they stay visible behind floating windows.

Sysadmins constantly juggle temporary information: IP ranges, staging URLs, generated passwords, and deployment checklists. Storing these in external note apps creates friction and risks pasting credentials into wrong windows. Sticky Notes keeps context tightly bound to each specific server.

Legacy Tools Replaced: Scattered text files, external note apps, lost scratchpad commands

🖥️ Interface Overview & Visual Controls

The Desktop Sticky Notes app places customizable, color-coded scratchpads directly on your server desktop workspace. Each note header features a color palette selector (Yellow, Blue, Green, Pink, Purple, Dark), a pin toggle (keep on top of all windows), and a trash button. The note body supports full Markdown rendering, checklist checkboxes, monospace code snippets, and live character counts.

Key Capabilities & Features

  • Per-Server Isolation: Notes created on "Production VPS" stay strictly on "Production VPS", preventing cross-server confusion.
  • Markdown Formatting: Supports headers, bold, italics, inline code, checklists (- [ ]), and markdown tables.
  • 6 Color Themes: Choose from Yellow, Cyan, Lavender, Emerald, Tangerine, and Dark Slate themes.
  • Always-on-Bottom Pinning: Pin notes directly to the desktop wallpaper layer so they never obstruct active windows.
  • Split & Preview Modes: Toggle between pure Markdown editing, live HTML preview, or split view.

📋 Prerequisites & Remote Host Requirements

  • Active SSH connection in SSH Desktop.
  • Works completely client-side with zero server storage requirements.

Step-by-Step How-To Tutorial

1. Creating a New Sticky Note

Click the 📌 Sticky Notes icon in the Dock or press Cmd/Ctrl + Alt + N. A new colored note appears on your desktop canvas. Type a title and start jotting down notes.

2. Formatting with Markdown & Checklists

Type standard markdown syntax:
### Server Migration Checklist - [x] Dump PostgreSQL database - [x] Rsync /var/www to staging - [ ] Update Cloudflare DNS records - [ ] Issue new SSL certificate
Checkboxes can be checked or unchecked with a single mouse click!

3. Organizing and Pinning to Desktop

Drag notes anywhere across the desktop canvas. Click the 📌 pin icon to anchor the note in place. Click the palette icon to change the note color to match your task urgency (e.g. Red for urgent, Green for done).

💡 Pro-Tips & Best Practices

  • Server-Specific Persistence: Notes created while connected to a specific server are automatically saved to that server's profile and restored whenever you reconnect.
  • Interactive Checklists: Use standard markdown syntax (- [ ] Step 1) to create interactive task checklists that you can check off during deployments.
  • Pin Token & IP References: Pin a small note in the corner of your screen with temporary database passwords, API endpoints, or staging IP addresses for instant reference.
  • Search Notes: Use Spotlight (Cmd/Ctrl + K) to search across all your notes across all servers instantly.

Under the Hood: Linux Commands & Architecture

Notes are stored locally in the client's encrypted storage vault keyed to the specific server UUID. Optionally, notes can be synced to a hidden ~/.sshdesktop/notes.json file on the remote host if team sharing is enabled.

Primary Commands / Virtual Files Executed Over SSH:
Local state synchronization, Markdown parser, client storage

❓ Troubleshooting & Frequently Asked Questions

Notes not showing when opening app

Ensure the "Desktop Notes Visible" toggle is enabled in Desktop View settings (Cmd/Ctrl + Shift + N).
