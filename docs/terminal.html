⌨️ Interactive PTY Terminal (Xterm.js)

High-performance interactive PTY terminal emulator powered by Xterm.js with WebGL hardware acceleration, tabs, split panes, 24-bit TrueColor, font ligatures, and session persistence.

Figure: Real-time visual interface of Interactive PTY Terminal (Xterm.js) in SSH Desktop.

What is this Application & Why Do You Need It?

The Interactive PTY Terminal is a fully featured, GPU-accelerated terminal emulator built directly into SSH Desktop. It leverages Xterm.js with WebGL rendering to deliver high-speed scrolling, TrueColor graphics, full ANSI escape sequence support, and native pseudo-terminal (PTY) emulation for Linux shells (bash, zsh, fish).

Developers and sysadmins spend hours in the terminal. Traditional terminals either lack modern GUI integration or suffer from slow rendering and high CPU usage. SSH Desktop's terminal provides lightning-fast WebGL rendering, intuitive horizontal and vertical split panes, customizable themes, and seamless clipboard sharing.

Legacy Tools Replaced: PuTTY, iTerm2, Alacritty, Kitty, Windows Terminal

🖥️ Interface Overview & Visual Controls

The PTY Terminal provides a GPU-accelerated terminal experience powered by Xterm.js and WebGL. The Tab Bar at the top allows opening multiple shell tabs and naming sessions. The Split Pane Toolbar includes buttons to split the active terminal horizontally (Cmd+D) or vertically (Cmd+Shift+D). The main terminal canvas supports 24-bit TrueColor, clickable URL hyperlinks, and mouse-based text selection with automatic clipboard copy.

Key Capabilities & Features

  • WebGL Hardware Acceleration: Renders thousands of lines of log streams at 60 FPS with near-zero CPU usage.
  • Split Panes: Split terminal horizontally (Cmd+\) or vertically (Cmd+Shift+\) to monitor multiple commands at once.
  • Tabbed Sessions: Open unlimited terminal tabs with custom titles and color coding.
  • TrueColor & Font Ligatures: Full support for 24-bit RGB colors, powerline symbols, nerd fonts, and programming ligatures (e.g. Fira Code, JetBrains Mono).
  • Copy on Select: Highlight any text to copy immediately to your system clipboard; right-click to paste.

📋 Prerequisites & Remote Host Requirements

  • Standard OpenSSH server on the remote host.
  • Default user shell (e.g. /bin/bash, /bin/zsh, /bin/sh).

Step-by-Step How-To Tutorial

1. Opening and Splitting Terminal Sessions

Launch the terminal by clicking the Terminal icon in the Dock or pressing Cmd/Ctrl + T. To split the screen:
  • Press Cmd/Ctrl + \ to split horizontally into top/bottom panes.
  • Press Cmd/Ctrl + Shift + \ to split vertically into side-by-side panes.
  • Drag the separator bar to resize panes to your preference.

2. Customizing Fonts, Colors & Themes

Click the ⚙️ settings icon in the terminal window to customize:
  • Color Themes: Choose from Catppuccin, One Dark, Dracula, Solarized, Nord, or custom RGB palettes.
  • Typography: Select your preferred monospace font, font size (10px to 24px), line height, and toggle font ligatures.
  • Cursor Styles: Block, underline, or vertical bar with optional blinking.

3. Searching Terminal History

Press Cmd/Ctrl + F inside the terminal to open the search bar. Type any string or regex to find command outputs, error traces, or IP addresses in your terminal scrollback buffer.

💡 Pro-Tips & Best Practices

  • Split Panes for Multitasking: Split your terminal window into 2, 3, or 4 sub-panes to watch logs on the left while editing configurations on the right.
  • Broadcast Input: Enable "Broadcast Mode" from the tab menu to type a shell command once and execute it simultaneously across all open split panes.
  • Built-in Search (Cmd/Ctrl + F): Quickly search terminal buffer history with regular expression matching and match highlighting.
  • Copy on Select: Highlighting text with your mouse copies it to your clipboard automatically without needing to press keyboard shortcuts.

Under the Hood: Linux Commands & Architecture

The Rust backend requests a pseudo-terminal channel from the remote sshd using pty_req("xterm-256color", cols, rows) and spawns the user's login shell via shell(). Terminal resize events (SIGWINCH) are sent automatically on window resize.

Primary Commands / Virtual Files Executed Over SSH:
pty::openpty(), Xterm.js WebGL addon, UTF-8 streaming

❓ Troubleshooting & Frequently Asked Questions

Special characters or Nerd Font glyphs look broken

Ensure a Nerd Font (e.g. JetBrains Mono Nerd Font, Fira Code) is installed locally on your PC and selected in Terminal Preferences → Font Family.

Terminal size does not match remote nano/vim

SSH Desktop automatically transmits SIGWINCH terminal resize signals. If misaligned, type reset or click Terminal → Re-Fit Window Dimensions.
