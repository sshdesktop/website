👥 User & Sudoers Administration

Manage Linux users, secondary groups, and SSH authorized keys. Safely edit /etc/sudoers with automated visudo syntax validation to prevent lockouts.

Figure: Real-time visual interface of User & Sudoers Administration in SSH Desktop.

What is this Application & Why Do You Need It?

The User & Sudoers Administration tool is a visual account management suite for Linux. Create users, assign home directories, configure secondary groups (e.g. sudo, docker), import public SSH keys into authorized_keys, and safely modify sudo privileges.

Accidentally making a typo in /etc/sudoers using a standard editor can lock you out of root access permanently. Adding users and setting up SSH keys via CLI requires running multiple commands with strict permission flags. SSH Desktop validates sudo syntax automatically and automates key provisioning.

Legacy Tools Replaced: useradd, usermod, visudo CLI, manual ~/.ssh/authorized_keys editing

🖥️ Interface Overview & Visual Controls

The User & Sudoers Administrator provides safe, visual account management for Linux servers. The Users Tab lists all system and regular users with UID, GID, Primary Group, Login Shell, Home Directory, and Password Status. The Groups Tab manages Linux user groups and secondary group memberships. The Active Sessions Tab displays currently logged-in TTY/SSH users with IP addresses and login times, allowing instant session termination. The Sudoers Editor features Monaco-powered syntax validation with automated visudo testing before saving.

Key Capabilities & Features

  • 3 Dedicated Admin Tabs: Users Manager, Groups & Memberships, and Active Login Sessions (w/who).
  • SSH Key Provisioning: Add and revoke SSH public keys for any user with automated permission enforcement (chmod 700 ~/.ssh && chmod 600 authorized_keys).
  • Safe Sudoers Editor: Edit sudo privileges with automated visudo -cf syntax validation before saving to prevent lockouts.
  • Active Sessions Monitor: Inspect logged-in TTY sessions, remote IP addresses, idle times, and terminate unauthorized connections.
  • Account Lock / Unlock: Instantly disable compromised or inactive accounts without deleting home directory data.

📋 Prerequisites & Remote Host Requirements

  • Root access or an account with sudo privileges to manage users and permissions.

Step-by-Step How-To Tutorial

1. Creating a New User Account

Click + New User. Enter username, password, select default shell (e.g. /bin/bash), and check Grant Sudo Access if required. SSH Desktop creates the user and provisions their home directory.

2. Adding an SSH Authorized Key

Select a user and click SSH Keys. Paste the public key (e.g. ssh-ed25519 AAAAC3... user@laptop) and click Save Key. SSH Desktop creates the .ssh directory with correct ownership and permissions.

3. Editing Sudoers Rules Safely

Switch to the Sudoers Rules tab. Add passwordless sudo entries or custom command restrictions. When you click Save, SSH Desktop writes to a temporary file and runs visudo -c. If any syntax error exists, the save is aborted with a clear explanation, keeping your server safe!

💡 Pro-Tips & Best Practices

  • Safe Sudoers Editing: Never edit /etc/sudoers with plain text editors. SSH Desktop automatically validates the syntax with visudo -c before committing changes to prevent accidental root lockout.
  • Visual Authorized Keys Management: Click "SSH Keys" next to any user to view, add, or revoke SSH public keys without navigating to ~/.ssh/authorized_keys.
  • Lock Dormant Accounts: Click "Lock Account" to temporarily disable password login for ex-employees or inactive users without deleting their files.
  • Terminate Stale Sessions: Switch to the Sessions tab to view ghost SSH sessions from dropped Wi-Fi connections and terminate them cleanly with one click.

Under the Hood: Linux Commands & Architecture

Wraps useradd, usermod, userdel, and passwd. Sudoers verification uses visudo -cf /tmp/sudoers.test before atomically replacing the production config.

Primary Commands / Virtual Files Executed Over SSH:
useradd, passwd, usermod -aG sudo, visudo -c, /etc/passwd

❓ Troubleshooting & Frequently Asked Questions

visudo syntax check failed on save

The sudoers rule you typed has a syntax error. SSH Desktop prevents saving corrupted sudoers files to protect you from losing sudo access. Correct the highlighted error and try again.

User cannot login after creation

Ensure a valid login shell (e.g. /bin/bash) is assigned and that either a password is set or an SSH public key is added to their account.
