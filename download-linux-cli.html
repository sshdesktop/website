Linux Systemd Service Commands

Control and monitor the SSH Desktop daemon background service on your Linux server:

Start the SSH Desktop Daemon:

systemctl start sshdesktop

Instantly starts the server-side engine.

Enable Auto-Start on System Boot:

systemctl enable sshdesktop

Registers the service with systemd to launch automatically upon server reboot.

Verify Active Service Status:

systemctl status sshdesktop

Check operational health, memory footprint, and recent journal log entries.

View Initial Admin Credentials & Access Token:

sudo cat /var/lib/sshdesktop/initial-admin-credentials.txt

Display generated administrative credentials, one-time authentication token, and web console URL.

Quick Server Package Installation

  1. Install on Debian / Ubuntu

    sudo dpkg -i sshdesktop-server-linux-x64.deb

  2. Install on RHEL / Fedora

    sudo rpm -Uvh sshdesktop-server-linux-x64.rpm

  3. Enable & Start Systemd Service

    sudo systemctl enable sshdesktop && sudo systemctl start sshdesktop

  4. View Initial Admin Credentials

    sudo cat /var/lib/sshdesktop/initial-admin-credentials.txt

    Print generated administrator username, secure password, and local access URL.
