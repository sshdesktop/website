Install via Linux Package Repositories

Arch Linux (AUR):

yay -S ssh-desktop-bin

Official APT Repository (Debian / Ubuntu):

curl -fsSL https://repo.sshdesktop.com/gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/sshdesktop.gpg

Quick Installation via Terminal

For Debian & Ubuntu:

sudo apt install ./ssh-desktop_2.4.2_amd64.deb

For Fedora & RHEL:

sudo dnf install ./ssh-desktop-2.4.2.x86_64.rpm

For AppImage (Any distro):

chmod +x SSH-Desktop-2.4.2.AppImage && ./SSH-Desktop-2.4.2.AppImage
