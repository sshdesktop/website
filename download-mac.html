How to Install SSH Desktop on macOS

  1. Open the DMG File

    Double-click the downloaded SSH-Desktop-2.4.1-Universal.dmg in your Downloads directory.

  2. Drag to Applications

    In the Finder window that pops up, drag the SSH Desktop icon into your Applications folder.

  3. Launch from Spotlight or Launchpad

    Press Cmd + Space, type "SSH Desktop", and hit Return. Because the app is Apple-notarized, Gatekeeper opens it immediately without security warnings.
