How to Install SSH Desktop on Windows 11/10

  1. Download the Installer

    Click the download button above to get the official ssh-desktop-setup-2.4.1-x64.exe file.

  2. Run the Setup Wizard

    Launch the downloaded executable. Windows SmartScreen may verify the verified publisher certificate. Click "Next" to choose your installation directory.

  3. Import Existing SSH Keys & PuTTY Sessions

    SSH Desktop will automatically detect your C:\Users\<Username>\.ssh directory and PuTTY registry entries. Click "Import" to migrate all profiles in one click.
