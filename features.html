FAQ

Frequently Asked Questions

Got questions about SSH Desktop features? Here are answers to the most common questions.

Does SSH Desktop require installing any packages on my Linux server?

No. SSH Desktop connects natively over standard OpenSSH (port 22). It uses standard POSIX commands, /proc filesystem parsing, and native SFTP subsystem channels. Your server remains 100% clean with zero background daemons.

How does SSH Desktop achieve 0% extra server RAM usage?

Traditional remote desktop software (VNC, RDP, XRDP) runs a full desktop environment (XFCE, GNOME) on the server, consuming 1GB to 2GB of RAM. SSH Desktop executes all rendering locally on your client machine using WebGL and hardware acceleration, communicating via standard SSH2.

Can I manage 10+ servers simultaneously?

Yes. The multi-server horizontal tab bar lets you maintain concurrent connections across different VPS instances, cloud providers (AWS, Hetzner, DigitalOcean), and local Raspberry Pis with zero performance penalty.
