Detailed Step-by-Step Installation Instructions

1

macOS Installation Steps

  1. Download the official SSH Desktop Universal DMG package.
  2. Double-click the downloaded .dmg file in your Downloads folder to mount the disk image.
  3. Drag the SSH Desktop application icon into your /Applications shortcut folder.
  4. Eject the disk image and launch SSH Desktop from Spotlight (Cmd + Space) or Launchpad.
  5. On first launch, macOS Gatekeeper verifies the developer signature automatically. If prompted, click Open.
2

Windows 11 & Windows 10 Installation Steps

  1. Download the signed SSH Desktop .msi installer or portable executable.
  2. Double-click the installer and follow the quick setup wizard (installs into %LOCALAPPDATA%\Programs\SSH Desktop).
  3. If using Windows 10 and prompted for Microsoft Edge WebView2, click Install (pre-installed by default on Windows 11).
  4. Launch SSH Desktop from the Start Menu or desktop shortcut.
  5. Your SSH private keys and passphrases are safeguarded using Windows Credential Manager (DPAPI).
3

Linux Desktop Installation Steps

  • Universal AppImage: Run chmod +x sshdesktop*.AppImage && ./sshdesktop*.AppImage to run instantly on any distribution without root privileges.
  • Ubuntu / Debian (.deb): Run sudo dpkg -i sshdesktop*.deb || sudo apt-get install -f.
  • Fedora / Rocky / RHEL (.rpm): Run sudo rpm -i sshdesktop*.rpm or sudo dnf install ./sshdesktop*.rpm.
  • Arch Linux: Install via your AUR helper: yay -S sshdesktop-bin.
