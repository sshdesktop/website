FAQ

Frequently Asked Questions

What prevents running a dangerous command on production servers by mistake?

SSH Desktop has an intelligent risk analyzer: if your snippet contains destructive commands like rm -rf /, dd, reboot, or mkfs, it presents a red security modal requiring you to type "CONFIRM" and reviews the exact host list before executing.

Can I run scripts sequentially with fail-on-error stops?

Yes. You can switch between "Parallel All" mode and "Sequential Rolling" mode with an option to halt the rollout if any single host returns a non-zero exit code.

Can I export execution outputs and exit codes?

Yes. All output logs across all nodes can be exported as a consolidated JSON or CSV file for audit trails and compliance records.
