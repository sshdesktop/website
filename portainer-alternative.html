FAQ

Frequently Asked Questions

Do I need to uninstall Portainer before using SSH Desktop?

No. SSH Desktop communicates directly with Docker through the Linux socket. You can run SSH Desktop alongside Portainer or stop the Portainer container anytime to reclaim server memory.

Can I manage Docker Compose stacks?

Yes. SSH Desktop groups containers by compose project label, letting you restart or inspect multi-container microservice stacks with ease.

What permissions does my SSH user need?

Your SSH user simply needs to belong to the docker group on the host (sudo usermod -aG docker $USER), or have standard sudo permissions.
