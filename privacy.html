Privacy Policy

Effective Date: October 25, 2026 • Version 2.4.2

Summary in Plain English

SSH Desktop collects zero personal data, zero telemetry, and zero analytics. We do not operate any user account servers or cloud databases. Your server hostnames, IP addresses, SSH keys, passwords, and sessions remain strictly on your local computer.

1. Information We Do Not Collect

When you download and run SSH Desktop, the application does not transmit any of the following:

  • No IP addresses or remote hostnames.
  • No SSH private keys, passphrases, or passwords.
  • No session duration, commands executed, or application telemetry.
  • No hardware identifiers, MAC addresses, or device fingerprints.

2. How Credentials Are Stored

All saved session credentials and SSH keys are stored exclusively on your local device and encrypted using the host operating system's native hardware-backed cryptographic vaults:

  • Windows: Windows Credential Manager and DPAPI (Data Protection API).
  • macOS: Apple Keychain with Secure Enclave hardware isolation.
  • Linux: Freedesktop Secret Service API (libsecret).

3. Direct Network Connections

SSH Desktop establishes peer-to-peer SSH2, SFTP, and port-forwarding network sockets directly between your local computer and your remote server (usually on port 22). No intermediate proxy, relay server, or cloud gateway is ever used.

4. Third-Party Services

SSH Desktop contains no third-party software development kits (SDKs), no tracking pixels, and no advertising networks.

5. Open Source Verifiability

Our source code is publicly auditable under the Apache 2.0 and MIT open-source licenses. Security professionals and independent researchers can verify our zero-telemetry claims by inspecting network socket activity using Wireshark or tcpdump.

6. Contact Information

For privacy or security inquiries, refer to our security policy at security.txt or contact our security team at security@sshdesktop.com.
