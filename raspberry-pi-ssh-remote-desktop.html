Step-by-Step Guide

How to SSH into Raspberry Pi from Windows 10 & 11

Follow this tested runbook to connect to your Raspberry Pi remotely in 3 easy steps.

1

Enable SSH on Raspberry Pi OS

If you haven't enabled SSH yet, simply place an empty file named ssh (no extension) in the root of the microSD boot partition, or run Raspberry Pi config on the Pi terminal: 

sudo raspi-config
# Navigate to: Interface Options -> SSH -> Enable
2

Connect Using SSH Desktop

Launch SSH Desktop on your Windows 10/11 or Mac. Click New Server:

  • Host / IP: raspberrypi.local or local IP (e.g. 192.168.1.50)
  • Port: 22 (Standard SSH)
  • User: pi (or your custom username)
  • Authentication: Password or Ed25519 / RSA private key
3

Raspberry Pi Remote SSH FAQs

Common technical questions on connecting to Raspberry Pi remotely.

How do I find my Raspberry Pi's IP address?

On your Windows PC or Mac connected to the same Wi-Fi, open terminal and type ping raspberrypi.local or check your home router's DHCP client list. Once found, enter that IP into SSH Desktop.

Can I tunnel Windows RDP through SSH to Raspberry Pi?

Yes! If your Pi runs XRDP, you can establish an encrypted tunnel using SSH Desktop's RDP over SSH tool to forward port 3389 securely without exposing it to the local network.

Does it work with Raspberry Pi Zero and Zero 2 W?

Yes! Because SSH Desktop requires 0 MB extra RAM on the Pi, it is the ideal remote GUI client for resource-constrained devices like the Raspberry Pi Zero and Zero 2 W that would normally freeze under VNC.
