Frequently Asked Questions

Common questions about the interactive PTY terminal emulator.

What terminal emulation standard is supported?

SSH Desktop advertises TERM=xterm-256color or TERM=xterm-ghostty. It supports full VT100, VT220, VT520, ANSI X3.64, and modern extended OSC/CSI escape sequences for OSC 52 clipboard access, OSC 8 hyperlinks, and bracketed paste mode.

Does copy and paste work with standard system shortcuts?

Yes. Both macOS shortcuts (Cmd + C / Cmd + V) and Windows/Linux shortcuts (Ctrl + Shift + C / Ctrl + Shift + V) are natively supported, as well as automatic "Copy on select" with mouse marquee.

Can I connect using SSH keys with passphrases?

Yes. SSH Desktop integrates with your system's OpenSSH agent (Pageant, ssh-agent, 1Password Agent) and includes a zero-knowledge local key vault supporting RSA 4096, Ed25519, and FIDO2 YubiKeys.
