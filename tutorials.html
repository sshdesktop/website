SSH Desktop Server Management Tutorials

Comprehensive, end-user tutorials for everyday Linux server administration. Master Docker containers, encrypted database tunnels, SFTP, Nginx reverse proxying, and firewall rules.

1

Connecting to a New Linux Server & Setting Up Ed25519 Keys

Learn how to generate modern elliptic-curve Ed25519 cryptographic keys, copy your public key to the remote host, and configure your first connection profile in SSH Desktop.

Step 1: In terminal, run ssh-keygen -t ed25519 -C "admin@sshdesktop".
Step 2: Copy to remote server: ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server-ip.
Step 3: In SSH Desktop, click + New Connection, enter your server IP, port 22, and select your private key.
Step 4: Click Connect to launch your visual cloud desktop immediately.

2

Deploying & Managing Docker Stacks Visually

Control container lifecycles (Start, Stop, Restart, Kill), stream real-time container logs with regex filtering, and open interactive exec bash shells without memorizing docker CLI flags.

Step 1: Open Docker Hub from the Dock.
Step 2: Switch to the Compose Editor tab to write or edit your docker-compose.yml.
Step 3: Click Build & Run to pull images and deploy containers in the background.
Step 4: Click the terminal icon next to any container to launch an interactive /bin/bash shell.
Read full Docker Management Hub Guide →
3

Accessing Private Databases Over Encrypted SSH Tunnels

Safely connect to PostgreSQL, MySQL, MariaDB, and Redis listening only on remote 127.0.0.1 without opening dangerous database ports to the public internet.

Step 1: Launch Database Studio.
Step 2: Select your database engine (Postgres, MySQL, Redis, SQLite).
Step 3: Enter remote port (e.g. 5432 or 3306) and database credentials.
Step 4: SSH Desktop opens a transparent Direct-TCPIP tunnel and displays schemas, tables, and query editor.
Read full Database Studio Guide →
4

Dual-Pane SFTP File Management & In-Place Archive Extraction

Drag and drop files to upload, edit remote code files in Monaco, adjust file permissions (chmod), and unpack .tar.gz or .zip archives directly on the server without downloading.

Step 1: Open SFTP File Manager.
Step 2: Drag folders from your local computer into the remote file pane.
Step 3: Right-click any .tar.gz file and select Extract Here.
Step 4: Right-click files to edit in Monaco Editor with automated sudo elevation on save.
Read full SFTP File Manager Guide →
5

Visual UFW Firewall Configuration & Fail2ban Management

Protect your server from brute-force attacks: configure UFW rules visually with automated SSH lockout protection, restrict port access by IP subnet, and unban locked IP addresses.

Step 1: Open Visual Firewall (UFW).
Step 2: Verify that port 22 is allowed before enabling the firewall.
Step 3: Click Add Rule to open web ports (80 HTTP, 443 HTTPS) or limit SSH attempts.
Step 4: Switch to the Banned IPs tab to unban false-positive IP blocks from Fail2ban.
