Frequently Asked Questions

Common questions regarding webhook automated deployment.

Do I need to keep my client app open to receive webhooks?

In client desktop mode, the webhook receiver operates through an encrypted reverse tunnel while your app is running. In CLI server mode, the lightweight standalone daemon runs continuously in the background on your server host.

Can I restrict webhooks by Git branch?

Yes. You can configure branch filters (e.g. only trigger on pushes to main or production, while ignoring feature branches).
